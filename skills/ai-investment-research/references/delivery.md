# 综合报告与交付

默认语言中文，专业名词保留可检索原名。主报告是供用户阅读的研究结论，不展示内部工具实现细节或假装持牌机构出品。使用 [报告模板](../assets/report-template.md) 作为完整研究参考；单模块删去不适用章节，保持其必要证据、期限和限制。

## 产物与状态

- `04_deliverables/report.md`：真实撰写的完整主稿。脚本初始化不会生成虚假正文。
- 默认 MD＋独立 HTML＋PDF；发布器的 PDF 文件名由 content.filename 指定。Word 是可选格式，只有实际成功的文件才列为交付。
- `01_sources/` 保存原始材料与来源记录；`03_models/` 保存财务、估值、假设与计算；`99_internal/` 保存校验/导出清单；它们可追溯但不全塞进用户主要交付列表。
- 用户只要求对话表格/结论时遵从，不强制额外文件。明确要求完整行研/投研文档时必须实际写出报告，不能只交目录或流程。
- 已有旧报告只做参考；“更新”还要做变更与到期预测复盘，旧文件保留。

## 完整报告内容

1. 摘要：重要结论、证据/分歧、适用期限、当前可确认与未知。
2. 研究合同与资料缺口：对象、代码/市场、截止日、币种/财年/单位、资料范围、方法、各模块状态；有限研究明确写有限。
3. 行业：定义、规模与量价、产业链、竞争、政策技术、趋势、行业估值；相关图/表直接服务判断。
4. 公司：经营模型、披露和财报质量、主财务/估值假设、合理价值、预期差；多家公司分别有明确来源和模型。
5. 前瞻：事件传导及三情景、技术条件目标、适用的宏观背景；**价值/路径/时间/条件分开**。
6. 反方与风险：反对主论点的证据、最敏感假设、失效和数据不足的影响。
7. 预测登记与跟踪：基准、目标/方向、日期、先行指标、触发/失效；旧预测实际复盘。
8. 附录：来源链接/发布日期/抓取日、指标定义与计算摘要、必要图表数据。

完整不等于固定页数。资料只能支持框架时标题明确“研究框架/资料缺口”，不能把空章节包装成完整行研。主报告事实数字引用 `[S001]`，表格每行或列统一说明口径；如果引用的来源只支持观点，不应标为已披露事实。

## 生成与检查

先人工/模型根据真实证据写MD，维护三份台账与模块状态。运行：

```text
python "SKILL_ROOT/scripts/research.py" check --run "ABS_RUN_DIR" --strict
python "SKILL_ROOT/scripts/research.py" render --run "ABS_RUN_DIR" --formats md,html,docx
```

默认 PDF 使用 [离线内容发布器](publisher_contract.md)，从已完成研究建立 content JSON 并生成同源 MD/HTML/PDF，读取真实目录、bounds 与 warning。不要同时向同一路径写两条导出流程。兼容的 `research.py render --formats html,pdf` 只尝试已存在浏览器，不下载不运行替代服务器；缺工具或执行失败报告 `unavailable/failed`，不能提供不存在/空白PDF。字体及依赖见 [runtime-notes.md](runtime-notes.md)。

导出器支持基本标题、段落、列表、表格、链接、代码块，以及**独占一行的本地PNG/JPEG图**。图片路径相对MD源稿，解析后必须在本次运行内，单图至多10MiB；HTML嵌入data URI、Word嵌入媒体，拒绝外链图/SVG并明确警告。复杂公式/合并单元格/双栏图文可能需本机可用Office/PDF技能补充。代码/内联HTML按文本处理，不运行资料中的脚本。图表必须来自真实数据；不能以装饰性AI图片替代数据图。

至少打开一个阅读版检查：中文字体、长表宽度、标题和链接、来源完整；Word/PDF需检查其真实文件而非只看文件名。无查看工具时写“结构校验已通过，视觉未检查”，不声称视觉验收完成。保留MD源稿，不因转换删除资料。

最终回复给关键结论与1—3个主要成品位置、研究截止日、已完成/有限的模块、重要数据及方法限制。若用户索要内部模型/证据则单独提供。预测命中率只有在样本、时间、评判标准和防事后偏差都可复查时才可报告。
