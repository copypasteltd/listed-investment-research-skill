# 报告出版与导出

[文档导航](../index.md) · [English](../en/publishing.md) · [完整内容合同](../../skills/ai-investment-research/references/publisher_contract.md)

## 选择导出路线

| 路线 | 输入 | 输出 | 依赖 |
|---|---|---|---|
| 核心导出 | 完整 `04_deliverables/report.md` 与研究台账 | MD、独立HTML、基础DOCX；已有浏览器可打印PDF | Python标准库，PDF另需已装浏览器 |
| 内容出版器 | 完整内容JSON与本地PNG/JPEG | 分页PDF、同源MD、独立HTML、PDF审计和清单 | ReportLab、PyMuPDF、Pillow及兼容本地字体 |

两者采用不同主源。出版器不替代研究，不核实每项事实，台账须另行检查。多图商务报告优先内容出版器；基础Word可用核心导出。两条路线可能覆盖运行内相同 `report.md/report.html`，切换前明确主源并保存，不把多轮覆盖误当独立版本。

## 使用内容出版器

```bash
python skills/ai-investment-research/scripts/publisher.py \
  --run /absolute/research-run --content 99_internal/content.json \
  --font-body /local/body.ttf --font-head /local/heading.ttf
```

顶层包含题目、证券、截止、行情口径、判断、文件名、最多三个封面指标及逻辑页。块类型有正文、小标题、注释、表格、本地图表和来源。完整结构见上方合同及[数据合同](data-contracts.md)。

图表只接受运行内PNG/JPEG，拒绝逃出目录的路径。用户文字转义处理，不执行任意HTML；不获取远程图片、脚本或字体。HTML把原始图像字节作为data URI嵌入，可单文件阅读。

## 版式与真实分页

A4白底黑字，克制横线和来源注释；逻辑页有明确起点。图像保留比例，图题/图/来源一起放置。目录按实际起页迭代生成，书签也指向真实页，不用手写猜测页码。

逻辑页可能自然延展。清单如实记录实际页数差异和 `warning`；这不表示允许忽略裁切。应检查真实文本/图片边界及成品。On与用友历史样本目录均为两页，其报告总页数已包括这些页面。

## 状态和异常处理

| 结果 | 含义 | 处理 |
|---|---|---|
| `pass` | 确定性结构检查通过 | 事实仍需复核，外观如有能力另看 |
| `warning` | 文件存在但有延页等已披露事项 | 读取每条提示，以实际映射为准 |
| `fail` | 版式/审计失败 | 修复重建，不当已验收文件交付 |
| 构建异常 | 内容、字体或渲染出错 | 看本次错误；旧清单不能证明新构建成功 |

读取 `99_internal/report_manifest.json` 和 `pdf-layout-audit.json`，不只看退出0；warning通常也返回非失败退出码，fail或异常为非零，具体以脚本与 `--help` 为准。

## 验收检查什么

- PDF实际页数、逻辑页到真实页映射。
- 文本可提取与中文覆盖。
- 正文预留区域内的文字/图像边界。
- 空白正文页和图表放置次数。
- 真实书签、来源链接和输入/输出哈希。

它不核对图内数字与数据是否一致，不判断投资观点真假，也不证明审美质量。如要声称目视验收，需另有图像模型或人工检查；没有时说明只完成结构验收。

## 字体和版权

使用CLI参数或 `AIR_FONT_BODY` / `AIR_FONT_HEAD`。中文需兼容的本地CJK字体，自动发现取决于环境。不随生成器打包版权系统字体，也不以屏蔽缺字提示强行通过。

## 保留研究输入

保存原始资料、标准化数据、计算脚本、正文、内容JSON、台账和复核。外部只分享用户授权的内容；要求导出报告不等于授权上传整个研究目录。
