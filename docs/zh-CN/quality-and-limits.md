# 质量控制与适用边界

[中文 README](../../README.zh-CN.md) · [文档索引](../index.md) · [English](../en/quality-and-limits.md)

本系统的质量目标是让证据、变换、假设、修正和成品可核对，而不是承诺研究永远正确。
`check --strict` 通过不代表事实真实、公允价值准确、预测有效或适合交易。
下述历史案例来自 2026-11-13 的项目内模型/正文复核记录，只说明当时版本如何发现问题和处理边界。
它们不是持续更新的公司观点，也不是前瞻预测验证、审计意见或投资业绩证明。

## 1. 不同检查回答不同问题

| 检查层 | 可以支持的结论 | 不能支持的结论 |
| --- | --- | --- |
| 来源登记 | 有来源入口、日期、期间和 ID | 原文真实、完整，或句子引用正确 |
| 结构检查 | 字段、枚举、引用关系、概率、路径和缺口披露符合已实现规则 | 所有重要缺陷已被发现 |
| 逐字段源核对 | 被抽核字段与所读版本相符 | 未抽核字段也正确、后续版本也通过 |
| 算术复算 | 指定公式和输入可重算 | 公式经济含义正确、假设合理 |
| 模型复核 | 发现口径冲突、双计和敏感性遗漏 | 精确现货公允价值或完整独立审计 |
| 出版审计 | 实际页数、文字/图片框、书签和链接等通过检查 | 图内标签、数据和研究结论正确 |
| 视觉检查 | 所看的页面字体、表格、图表和分页可读 | 没看页面或所有输出格式均已验收 |
| 预测复盘 | 原记录在给定窗口和规则下的结果 | 未建立样本和规则的“准确率” |

核心 `check` 在严格模式下把部分原本为 warning 的不完整事项提升为 error，但不是所有警告都会消失。
本地材料、未知发布日期和条件技术目标仍可能有提示；应阅读结果而不是只看退出码。
发布器 `warning` 也返回 0，不能将它改写为“严格通过”。

## 2. 地产开发商：HK09993 的三项模型纠错

历史模型是一项静态净账面压力测试，不能按它未给出 DCF 目标价就判定失败。
复核实际发现了以下三个可修正问题，并在后续最终报告复核中独立关闭。

| 发现 | 纠正与验证 | 方法含义 |
| --- | --- | --- |
| CFO 桥漏列 48.546 百万元人民币 | 补汇兑 −29.135、应收减值 +0.860、PPE 处置收益 −4.512、财务收入 −0.959、关联应付减少 −14.800；桥闭合至 CFO 1,215.276 | 约占 CFO 4% 的漏项不是舍入差 |
| NCI 两个归属假设称为“两边界” | 改称示例分摊情景，说明实际可在区间外 | 期末归母/总权益比例不能证明项目损失归属的上下限 |
| 负归母账面权益每股截零 | 保留 −5,723.0686 百万元及约 −HKD1.66844/股的带符号值 | 负账面数不等于负股价，零截断也不是价格底线 |

同期通过项也应保留：千元/百万元/亿元、归母 PB、参考汇率方向均可复算。
CFO 扣息、再移除两类应付增加属于诊断，并非重述 CFO、标准 FCF 或应付款已逾期的证明。
短债减少 3,954.443 百万元不等于同额现金偿债；毛债仅减少 94.990 百万元，期限迁移需另查。
已计入净账面的存量减值、担保与抵押资产不能再次机械追加为借款或损失。
子集团 CAS 九月数字不能拼成上市集团三季报，结转收入不能填补缺失合约销售。

后续正文复核还发现未获可比证据的“回款改善”、承债中的内部往来遗漏、可用到期桶未展示及两处页码问题。
记录显示这些由负责人确认处理；它同时明确没有独立复读重建成品，也未作视觉验收。
因此本页区分“独立关闭旧三项”与“负责人确认后四项”，不把通知当成重新验证。

## 3. 消费品牌：ONON 的口径与双计边界

历史复核确认 A/B 类股经济权利按面值分配：经济 A 等价股数为 `A + B/10`。
302,025,490 A 股加 324,991,680 B 股的十分之一为 334,524,658 A 等价股，不能用总票数作为估值分母。
期末经济股数、报告期加权 EPS 分母和未来稀释终点分别处理。

- 一次性退款：Q3 毛利率约 72.6%，剔除 CHF52.6 百万元退款后约 66.9%；单边调整不是官方双边同比正常化。
- 历史 FX：2021 纯汇兑损失 −16.3 与后续净汇兑字段口径不一致，修为净额约 −14.9，并保留子项 trace。
- 利润桥：明确舍入项从 −0.1 修为 −0.2 CHF 百万元，按已披露一位小数输入闭合至 371.0。
- 现金代理：9M CFO413.3 − Capex84.6 − 租赁本金61.3 − 现金付息20.2 = CHF247.2 百万元。
- 租赁与 SBC：既然未来现金代理已扣租赁本金，不再在股权桥重复扣全部租赁负债；SBC 用显式稀释处理时避免再次扣同项。

历史 FX 字段和桥接舍入项有独立复读关闭；没有因此把三情景 DCF 说成精确现货公允价值。
盘中报价、较早 FX、9 月现金和年末估值起点不同步，必须随结果披露。
现金全额加回仍是假设，未证明为超额可分配现金；未来流量还应排除单独加回现金的重复利息收益。
NWC 按舍入分项重算与公司原披露各差 0.1，应清楚标为两种口径。
最终正文复核对这两项补充只记录负责人计划，不能据此声称已独立复读补充后的文本。

## 4. 混合 ERP/云：用友的存量、流量与现金

历史复核通过了 Q3 单季与 9M−H1 差分、单位和包含 NCI 的合并恒等式。
它指出“模型数字算对”仍可能留下现金率和融资桥定义冲突。

| 易错点 | 本例说明的处理 |
| --- | --- |
| 云收入等同订阅/ARR | 云收入是期间流量，ARR 与订阅合同负债是时点 KPI；管理层合同负债与合并流动合同负债另列 |
| 开发支出余额等同资本化流量 | 9M 开发余额 756.221310 百万元不能直接当 9M 资本化投入；缺失流量保留 `null` |
| 研发投入等同纯现金 | 2025 总投入 2,427.070952 百万元含股权激励、折旧等，是资源耗用/权责口径，严格现金需再勾稽 |
| 全无形摊销等同研发摊销 | 全体无形摊销不全属于内部研发，不能据此编全费用化利润 |
| 未来 debt service 与桥接双扣 | 明确流量扣租赁本金、融资利息和持续研发现金，但不扣银行本金；桥不重复扣租赁 |
| 混合到期负债叫银行净债 | 未拆的一年内到期非流动负债含不确定融资成分，单列风险范围，不照搬 H1 构成 |

修订后主桥为现金等价物 1,608.665011 + 交易性金融资产 945.611823 − 已确认短借 4,371.118398 = −1,816.841564 百万元。
最终正文续核确认新桥与现金率边界已同步，但短借仍只是已确认借款下限，理财变现及经营现金需求仍是假设。
货币资金较现金等价物多 712.663241 百万元，不应全部称为受限现金；全额加回另作敏感性。
10 月融资到账不能回写 9 月资产负债表；申请 H 股不等于已募资。
后续正文复核仍发现研发“现金”措辞和六处图题/图源与实际序列不一致，记录为修订要求。
这说明图像数量和哈希即使正确，也不能证明图题、正文和数据语义一致。

## 5. 纠错闭环如何记录

1. 保存发现的版本、具体证据、严重度及对结论的实际影响。
2. 修改原始数据映射、公式或口径，随后同步模型输出、图表和正文。
3. 在修订后的版本上复算或复读，明确复验范围。
4. 标注独立复验、负责人确认、待复验或仍有限；保留原发现及修正理由。
5. 重新出版并读取本次 manifest/audit，旧成功记录不能覆盖新构建失败。

没有视觉输入的复核者应写“未视觉检查”，只读代码不能称已看过图像。
同一代理扮演不同角色属于自审；不存在独立执行就不声称独立审查。
修正范围应针对证据支持的实际问题，不为制造问题数而把已披露限制重复当错误。

## 6. 发布、演示和使用边界

合成离线示例是一等使用入口：用于学习目录、字段、检查和排版，不需要实时行情或厂商凭据。
历史发布案例是冻结快照，不能作为当前公司事实；其后披露、行情及企业行动需要重新核验。
固定上游版本保留原许可证和哈希；升级需重新核对来源，不执行上游文本中的自动更新或外发指令。
原始财报 PDF、行情数据库、第三方图表与付费资料的许可不随代码许可证转移，公开仓库不应自动再分发。

本方案不保证覆盖全部市场、公告和风险；离线材料、网络失败、抽样复核和未核实日期会限制结论。
代理现金流、终值、回报率、现金可用性和稀释都可能主导估值，应展示敏感性而非虚构精度。
没有样本、时间窗口、原预测、防事后修改和评判规则，不报告模型“准确率”。
研究授权不包含下单、资金操作、修改账户或自动对外发布；需要由用户另行明确授权。
交付时保留资料截止日、有限模块、未完成检查和重要假设，让读者知道结论在哪些条件下成立。
