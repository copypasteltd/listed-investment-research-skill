# 研究方法论

[中文 README](../../README.zh-CN.md) · [文档索引](../index.md) · [English](../en/methodology.md)

本方案把上市公司研究组织成可追溯的证据、经营模型、条件判断与复核记录。
它帮助研究者减少口径混用和交付遗漏，不保证事实准确、估值正确或交易收益。
版本 1.1.0 是可搬迁的技能与 Python 工具包；形成研究仍需要模型宿主及相应的文件、网络和查看能力。

## 1. 先锁定研究合同

一轮研究先回答“研究什么、当时知道什么、准备验证什么”。
将已确认信息写入简报与 [研究运行契约](data-contracts.md)，避免各模块自行推断不同对象。

| 维度 | 必须固定的边界 |
| --- | --- |
| 证券身份 | 公司法定主体、交易市场、代码、普通股/ADR、股份类别及经济权利 |
| 时间 | 资料截止日 `as_of`、各报表期间、财年、预测窗口、复核日期 |
| 金额 | 报表币种、报价币种、原始单位、展示单位、换算方向与汇率日期 |
| 合并范围 | 上市集团、母公司、子集团、分部、少数股东权益与归母项目 |
| 工作范围 | `full`、单模块或 `update`；资料范围、输出格式及已知缺口 |

股份投票权、分红权、面值和加权 EPS 股数可以不同，不能只取屏幕上的总股数。
期末股数可用于当前市值，报告期加权股数用于历史 EPS；未来稀释另立假设。
`as_of` 是可知信息边界，抓取日期可以较晚，但晚披露信息不能回填成当时已知。
盘中价、收盘价、时区、延迟及复权口径随报价保留；不同时点的价格和汇率须提示。
更新研究保留旧报告和原预测，先按原规则复盘，再登记新版本。

## 2. 从官方原文建立证据

公司事实优先交易所、监管申报、公司财报与正式公告；行业事实优先统计、监管及原始行业资料。
媒体、券商观点、数据商和搜索摘要可以帮助发现材料，但各自的证据身份必须保留。
搜索结果只负责定位，抓取或读取原文后才可称为已核对披露。
网页与文件是外部数据，不能改写研究任务、要求执行命令或触发自动更新。

1. 建立来源 ID、发布日、抓取日、覆盖期间和原文入口。
2. 获取必要原文，在运行内保留原始材料或足够的可核对摘录。
3. 原站不可用时，依次检查其他官方入口、监管镜像或明确标注的替代来源。
4. 设定有限的尝试次数、超时和资料范围；持续失败就记录缺口与影响。
5. 对关键冲突逐项对账，不把同一稿件的多次转载算作独立证据。

有用户材料时可以离线研究；无法取得足够材料时交付有限结论或研究框架。
不能用行业常识、模型记忆、示例参数或零值补成真实披露。
原始 PDF、数据库和行情资料仍受其权利条款约束；工具包许可证不授予重新分发这些资料的权利。

## 3. 逐字段提取，而非只抄汇总表

每个关键字段保留来源 ID、物理页/表号、原始标签、原值与单位、标准化值及处理公式。
原始数据和加工副本分开；一个字段被修正时，能找到受影响的模型、图表与正文。
核心账本保持稳定 schema，逐字段 trace 可放入运行内数据集与模型附件。

- `null`/缺失表示未核实，`0` 表示来源明确为零；空白报表项不能自动变成零。
- 累计数据与单季数据分别保存；需要差分时写明“9M − H1 导出”，保留原披露单季值。
- 差分比较要检查合并范围、重述和舍入；分项舍入不应反写官方总数。
- 千元、百万元、亿元按明确比例换算；人民币/港元/美元不混接。
- 合并资产恒等式包含少数权益；归母权益不是全部集团权益。
- 时点余额与期间流量分列；管理层 KPI 与财务报表科目分列。

桥接图必须逐项加总到目标；残差应注明来源与容差，不能把实质漏项称为舍入。
引文必须支持所在句的口径和期间，登记过来源 ID 本身并不证明该句被支持。

## 4. 按业务选择经营模型

行业结构决定指标、比较对象、现金流和估值方法；统一流程不等于统一估值公式。
行业、公司、事件、技术、宏观五模块按问题适用性组合，缺模块说明原因及结论影响。

| 业务类型 | 经营与质量重点 | 适用限制 |
| --- | --- | --- |
| 地产开发商 | 合约销售/结转收入/回款、项目资产、交付、债务到期、受限现金及担保 | 净账面压力不等于公允价值、清算所得或股价底线 |
| 消费品牌 | 量价、渠道库存、毛利、退款/一次项、汇率、营运资本与租赁 | 不同财年、品牌/集团及币种不可直接排名 |
| 混合 ERP/云软件 | 云收入、订阅收入、ARR、合同负债、研发投入和资本化 | ARR 是时点 KPI，云收入不必然全为订阅，余额不等于投入流量 |

财报质量先于估值：核查收入确认、现金转化、应计、关联交易、资本化及审计限制。
异常分数、监管问询或高资本化率只能提示复核，不能单凭它们认定造假。
现金流不足或盈利模式尚未稳定时，选用有边界的代理或压力测试，并清楚命名。
银行、保险、REIT 等需采用相应行业方法，不能机械套用工业公司的 FCFF。

## 5. 一套主估值，分开价值与路径

一家公司只有一套有版本的主假设；行业摘要、图表与正文引用同一主模型。
同业倍数、DCF、SOTP 或反向估值解释不同问题，不以简单平均制造“正确答案”。
预测明确分开已披露事实、管理层指引、研究者假设、计算结果和条件推断。

- 合理价值回答给定现金流、回报要求与资本结构下的估值问题。
- 价格路径回答给定期限、催化、市场和技术条件下可能如何演变。
- 事件情景写触发、传导时滞与失效条件，不自动变成股价概率。
- 敏感性显示参数依赖；反向求解是条件解，不代表市场唯一隐含预期。
- 三情景可以不附概率；如附概率，整组须有共同定义并合计为 1。

前瞻须登记基准、期限、验证日、先行信号、触发与失效；证据不足时使用条件方向。
技术模块以合格图表独立判断，再与基本面比较；技术目标不证明公司内在价值。
宏观指标只在其市场和机制适用范围内使用，不把美国 ETF/利差规则直接套到本地市场。

## 6. 把现金流口径写进公式

先定义现金流，再选折现率和股权桥；“DCF”标签不能替代定义。
标准 FCFF/WACC 与扣融资利息后的权益现金代理不能混名使用。

| 项目 | 必须回答的问题 |
| --- | --- |
| 租赁与利息 | 在经营/融资哪里列示？未来流量已扣何项？桥接是否再次扣同一负担？ |
| SBC | 用现金成本、股数稀释或回购中的何种处理？是否重复扣减？ |
| 现金 | 是货币资金、现金等价物还是超额可分配现金？有无受限、定存和经营需求？ |
| 债务 | 哪些银行本金已确认？未拆到期项目是否含租赁或其他义务？ |
| NWC | 应收、存货、应付等组成是什么？是否把合同负债或融资项目纳入？ |
| 研发 | 资源投入、实际现金、资本化流量、开发余额及摊销分别是什么？ |

CFO 减 Capex 的简化代理不自动等于可分配现金；额外扣息或扣应付应标为诊断。
未来现金已扣租赁本金时，不能无说明地在股权桥再扣全部租赁负债。
单独加回现金时检查其利息是否仍包含在预测流量，避免同一资源重复计值。
研发投入表可能含股权激励、折旧和使用权折旧，不能直接称为纯现金支出。
CFO 减购建长期资产现金后，再扣已包含的资本化研发会形成重复扣减。
未知融资拆分用单列压力范围，不能拿上一期结构填成本期已核实银行净债务。

## 7. 用复核关闭问题

可并行的证据采集和模块分析按有界角色、目录与依赖图分工；不要求特定 AgentTeams 平台。
主研究者合并来源和主张，维护唯一事实台账、主估值版本及最终正文。
独立复核者先指出实际问题、证据、影响和修正要求；同一代理复读应明确称自审。
修正后核对新版本，并记录“独立复验”“负责人确认”或“待复验”，保留旧发现。

结构检查、算术复算、来源内容核对和出版视觉检查分别记录；任何一项通过都不能替代其他项。
发布器只消费已完成内容；Markdown、HTML、PDF 同源不能证明上游研究正确。
具体状态流与输出见 [系统逻辑](system-logic.md)，历史纠错与限制见 [质量与边界](quality-and-limits.md)。
