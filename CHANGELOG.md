# Changelog / 更新记录

## 1.1.0 — 2026-11-13

- Package the research Skill as a standalone repository with English and Chinese READMEs and a matched documentation system. / 独立封装Skill、中英文README及完整文档体系。
- Add portable installation and settings without a machine-specific default workspace. Preserve existing unrelated host installations. / 去本机路径，增加非覆盖式安装。
- Include the offline PDF publisher and reusable data-chart helpers developed during three research deliveries. Add configurable local fonts and actual pagination/layout evidence. / 封装实战出版与制图能力，支持字体、真实分页和结构验收。
- Document the evidence-to-report flow, state model, source/claim/forecast contracts, accounting boundaries, review closure, and known limitations. / 系统说明方法、逻辑、合同、会计边界和复核。
- Provide an explicitly synthetic offline example and a report gallery with three dated public-information snapshots. / 提供明确合成示例与三份历史成品展示。
- Preserve five upstream methods from three pinned repositories with original license texts and per-file hashes. / 保留五个固定上游方法及许可证、哈希。
- Tighten chart arithmetic and portable tests around signed totals, missing values, paths and rendering. / 加强负值、缺失、路径和导出的验证。

This is a packaging/methodology release, not a new claim of predictive accuracy or unattended data coverage. / 本版本是封装与方法升级，不代表预测准确率或无人值守取数能力已验证。

## 1.0.0 — prior local integration

The first integration unified industry, company, event, technical and macro workflows, structural checks and basic exports. It was used for three research runs before this public package. Machine-local defaults and research-session material are not part of this release. / 首版本统一五模块、结构检查与基础导出，曾用于三份实战报告；本机设置和会话材料不纳入公开包。
